What both builds already do

Same content, same rules

Full brief coverage: overview, crews and crew ID, staff roles, five mission categories with sample missions, the points sheet, the target list and Dexter's desk, the board, run of day, the Big Heist, prizes, platform internals, control room, mission-idea lab, FAQ, registration.

Neither build invents mechanics: 60 + 25 + 15 + 10 − 5×hints per mission, top 3 crews listed each round, −20 % while wanted, 100 cash to clear with Dexter, top 5 reach the heist, +150 / +120 / +100 / +75 by finish position.

Live, interactive, offline

Scoring-sheet calculator, pay-Dexter-or-eat-the-20 % calculator, final-score calculator, category filter, idea-lab card builder with copy, SPEC tabs with copy buttons, a countdown to first light, and a city board you can push through three rounds, a target list, a clearance and the Big Heist.

Fonts, icons and imagery are all local (three.js only in Concept A). Unplug the network; the page still works.

Built for the day of

No page-level horizontal overflow at 390 / 768 / 1440 px, keyboard access and skip links, aria-live on async regions, reduced-motion respected, print stylesheet in both.

Zero console errors, zero broken references, verified in Chromium.

Hand-off

spec.md v2.0 is the endpoint contract the platform implements: crew + QR, mission attempts with speed derived server-side, target-list publication, wanted rules with photo opt-out, Dexter's clearance ledger, heist qualification and bonuses, board views, realtime envelope, penalties, tie-breaks and the audit.

Swap the demo board for GET /api/board and the page is live.

Run locally

cd vice-city
python -m http.server 8123
# http://localhost:8123/concept-a-neon-litho/
# http://localhost:8123/concept-b-material-vice/

Every path is relative, so either folder can be dropped on any static host — or a USB stick — without changing a line. Every event number lives in one place: the CONFIG object at the top of each build's assets/js/main.js (eventDate, dexterFee, wantedCut, heistBonus, hintCost, links).
